# WordFlash 微信小程序发布指南

## 一、准备工作

### 1. 注册微信小程序账号
1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 点击"立即注册" → 选择"小程序"
3. 填写邮箱、密码等信息完成注册
4. 进行主体认证（个人/企业）
   - 个人：需要身份证、手机号
   - 企业：需要营业执照、对公账户

### 2. 获取小程序 AppID
1. 登录微信公众平台
2. 进入"开发" → "开发管理" → "开发设置"
3. 复制"AppID(小程序ID)"

### 3. 下载微信开发者工具
1. 访问 [微信开发者工具下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 下载对应系统的稳定版
3. 安装并登录（使用小程序管理员微信扫码）

---

## 二、导入项目

### 1. 打开开发者工具
1. 点击"小程序" → "+"
2. 选择"导入项目"
3. 选择 `wordflash-miniprogram` 文件夹
4. 填写 AppID（从微信公众平台获取）
5. 点击"确定"

### 2. 配置项目
在 `app.json` 中确保已配置合法域名（如果有网络请求）：

```json
{
  "networkTimeout": {
    "request": 30000
  }
}
```

如需使用 AI 服务，需在公众平台配置服务器域名：
1. 微信公众平台 → 开发 → 开发管理 → 服务器域名
2. 添加 request 合法域名（如 `https://dashscope.aliyuncs.com`）

---

## 三、开发调试

### 1. 本地测试
- 在开发者工具中预览效果
- 使用"真机调试"在手机上测试
- 检查控制台是否有报错

### 2. 功能检查清单
- [ ] AI 生成词库功能正常
- [ ] 闪卡学习功能正常
- [ ] 单词列表显示正常
- [ ] 数据导入导出功能正常
- [ ] 语音朗读功能正常

---

## 四、上传代码

### 1. 代码上传
1. 开发者工具中点击右上角"上传"
2. 填写版本号（如 1.0.0）和项目备注
3. 点击"上传"

### 2. 提交审核
1. 登录微信公众平台
2. 进入"管理" → "版本管理"
3. 在"开发版本"中找到刚上传的版本
4. 点击"提交审核"

### 3. 填写审核信息
- **功能页面**：选择首页路径 `pages/index/index`
- **功能描述**：AI驱动的英语单词学习工具，支持智能生成词库和闪卡学习
- **测试账号**：如需测试账号，提供说明
- **备注**：说明 AI 功能需要用户自行配置 API Key

---

## 五、审核注意事项

### 1. 内容合规
- 确保没有违规内容
- AI 生成内容需符合规范
- 不涉及敏感词汇

### 2. 用户隐私
- 已在隐私政策中说明数据存储方式
- 不收集用户个人信息
- API Key 仅本地存储

### 3. 类目选择
建议选择以下类目：
- 教育 - 在线教育
- 工具 - 效率

### 4. 审核时间
- 一般 1-3 个工作日
- 节假日可能延长

---

## 六、发布上线

### 1. 审核通过
1. 收到审核通过通知
2. 登录公众平台 → 版本管理
3. 点击"发布"

### 2. 发布后
- 小程序可立即搜索到
- 生成小程序码供分享
- 可在"数据分析"查看使用情况

## 八、常见问题

### Q: 个人开发者可以发布吗？
A: 可以，但部分功能受限（如支付、部分类目）。WordFlash 属于工具类，个人开发者可以正常发布。

### Q: 审核被驳回怎么办？
A: 查看驳回原因，修改后重新提交。常见问题：
- 功能不完整
- 内容违规
- 类目选择不当

### Q: 需要服务器吗？
A: WordFlash 是纯本地存储的小程序，不需要自己的服务器。AI 功能调用第三方 API，用户自行配置。

### Q: 如何让用户知道需要配置 AI？
A: 已在首页和个人中心有明显提示，首次使用时会引导用户配置。
