# 微信小程序开发避坑指南

> 本文档记录了 WordFlash 小程序开发过程中遇到的所有 Bug 和解决方案，后续开发新功能时务必先参考本文档，避免重复踩坑。

---

## 一、WXML 模板语法限制

### ❌ Bug 1：不支持可选链操作符 `?.`

**错误信息：**
```
Bad attr `wx:if` with message: unexpected token `.`
Bad value with message: unexpected `>` at pos28
```

**错误写法：**
```xml
<text>{{deleteTarget?.name}}</text>
<text>{{relatedLibraries.find(item => item.id === excludeLibId)?.name}}</text>
<view wx:if="{{item.id !== deleteTarget?.id}}"></view>
```

**正确写法：**
```xml
<text>{{deleteTarget.name}}</text>
<text>{{excludeLibName}}</text>
<view wx:if="{{item.id !== deleteTargetId}}"></view>
```

**规则：** WXML 不支持任何 JavaScript 高级语法（`?.`、`??`、`?.[]` 等），所有数据访问必须用标准的点语法。如果数据可能为空，在 JS 中提前处理好再传给 WXML。

---

### ❌ Bug 2：不支持 `!==` 严格不等于

**错误信息：**
```
Bad attr `wx:if` with message: unexpected token `.`
```

**错误写法：**
```xml
<view wx:if="{{item.id !== deleteTarget?.id && item.category !== 'mastered'}}">
```

**正确写法：**
```xml
<view wx:if="{{item.id !== deleteTargetId && item.category !== 'mastered'}}">
```

**规则：** WXML 中 `!==` 和 `!=` 都可以用，但问题出在 `?.` 上。确保表达式中没有 `?.` 即可。

---

### ❌ Bug 3：不支持数组方法（find、filter 等）

**错误写法：**
```xml
<text>{{relatedLibraries.find(item => item.id === excludeLibId)?.name}}</text>
```

**正确写法：**
在 JS 中提前计算好：
```javascript
onExcludeLibChange(e) {
  const id = e.detail.value === '' ? null : parseInt(e.detail.value);
  const lib = id ? this.data.relatedLibraries.find(l => l.id === id) : null;
  this.setData({
    excludeLibId: id,
    excludeLibName: lib ? lib.name : ''  // 提前计算，传给 WXML
  });
}
```

**规则：** WXML 的 `{{}}` 表达式中**不能调用函数**（包括 `find`、`filter`、`map`、`parseInt` 等）。所有计算必须在 JS 中完成，通过 `setData` 传给模板。

## 二、app.json 配置问题

### ❌ Bug 4：引用了不存在的页面

**错误信息：**
```
["pages"][4] could not find the corresponding file: "pages/ai-generate/ai-generate.wxml"
```

**原因：** `app.json` 的 `pages` 数组中引用了一个页面路径，但对应的 `.wxml` 文件不存在。

**解决方案：**
- 如果页面不需要了，从 `pages` 数组中删除
- 如果需要该页面，创建对应的 `.js`、`.wxml`、`.wxss`、`.json` 四个文件

**规则：** `app.json` 中的每个页面路径都必须有对应的四个文件（`.js`、`.wxml`、`.wxss`、`.json`），缺一不可。

---

### ❌ Bug 5：tabBar 图标文件不存在

**错误信息：**
```
["tabBar"]["list"][0]["iconPath"]: "assets/icons/library.png" not found
```

**原因：** `app.json` 中配置的 tabBar 图标路径指向了不存在的文件。

**解决方案：**
- tabBar 图标必须是**本地文件**，不能是网络图片
- 图标格式必须是 **PNG**
- 图标大小建议 **81×81 像素**
- 未选中图标和选中图标是两个不同的文件

**规则：** tabBar 的 `iconPath` 和 `selectedIconPath` 必须是本地 PNG 文件路径，且文件必须存在。

## 三、项目配置问题

### ❌ Bug 6：Cloud Base vs No Cloud Service

**场景：** 导入项目时需要选择 "Cloud Base" 或 "No Cloud Service"。

**选择规则：**
- **纯本地存储的小程序** → 选 **No Cloud Service**
- **需要微信云开发** → 选 **Cloud Base**

**WordFlash 选择：** No Cloud Service（数据全部存储在本地，不需要云服务）

---

### ❌ Bug 7：Intel Mac 下载了 ARM64 版本

**规则：**
- Intel 芯片 Mac → 下载 **x64** 版本
- Apple Silicon（M1/M2/M3/M4）→ 下载 **arm64** 版本

**确认芯片方式：**
- 苹果图标 → 关于本机 → 查看芯片类型
- 终端命令：`uname -m`（输出 `x86_64` 为 Intel，`arm64` 为 Apple Silicon）

---

## 四、网络请求问题

### ❌ Bug 8：未配置合法域名

**错误信息：**
```
request:fail url not in domain list
```

**原因：** 小程序只能请求在微信公众平台配置过的域名。

**解决方案（开发阶段）：**
- 微信开发者工具 → 详情 → 本地设置 → 勾选 **"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"**

**解决方案（上线阶段）：**
- 微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名
- 添加 `request 合法域名`：
  - `https://dashscope.aliyuncs.com`（AI 服务）
  - `https://dict.youdao.com`（有道词典）

**规则：** 开发阶段勾选"不校验"即可，上线前必须配置合法域名。

---

### ❌ Bug 9：请求超时

**解决方案：** 在 `app.json` 中配置 `networkTimeout`：
```json
{
  "networkTimeout": {
    "request": 30000,
    "downloadFile": 30000,
    "uploadFile": 30000,
    "connectSocket": 30000
  }
}
```

## 五、WXML 数据绑定注意事项

### ❌ Bug 10：访问未初始化的数据属性

**错误写法：**
```xml
<text>{{library.name}}</text>
```
如果 `library` 为 `null`，会报错。

**正确写法：**
在 `onLoad` 中确保数据已初始化：
```javascript
onLoad() {
  this.setData({ library: db.getLibraryById(id) });
}
```
或在 WXML 中加判断：
```xml
<block wx:if="{{library}}">
  <text>{{library.name}}</text>
</block>
```

**规则：** WXML 中访问对象属性前，确保对象不为 `null`/`undefined`。用 `wx:if` 或 `block` 包裹做判空处理。

## 六、开发工具使用

### 💡 编译快捷键

| 操作 | Windows | Mac |
|------|---------|-----|
| 编译 | `Ctrl + B` | `Cmd + B` |
| 清缓存 | 菜单 → 工具 → 清缓存 | 同左 |
| 真机调试 | 工具栏按钮 | 同左 |

### 💡 代码修改后自动编译

- 保存 `.js`、`.wxml`、`.wxss`、`.json` 文件后会自动重新编译
- `app.json` 修改后**不会**自动编译，需要手动点击编译按钮

## 七、WXML 模板语法速查（禁止事项）

| 禁止语法 | 替代方案 |
|---------|---------|
| `{{obj?.prop}}` | `{{obj.prop}}`（JS 中提前判空） |
| `{{a ?? b}}` | `{{a || b}}` |
| `{{arr.find(...)}}` | JS 中计算后 setData |
| `{{arr.filter(...)}}` | JS 中计算后 setData |
| `{{parseInt(x)}}` | JS 中计算后 setData |
| `{{new Date()}}` | JS 中格式化后 setData |
| `{{JSON.stringify(x)}}` | JS 中序列化后 setData |
| 三元运算嵌套过深 | 用 `wx:if` / `wx:elif` / `wx:else` |

## 八、文件结构规范

每个页面必须包含以下四个文件：

```
pages/xxx/
├── xxx.js      # 页面逻辑
├── xxx.wxml    # 页面模板
├── xxx.wxss    # 页面样式
└── xxx.json    # 页面配置（可以为空 {}）
```

**注意：** 即使 `xxx.json` 没有内容，也必须创建一个空文件 `{}`，否则可能报错。
