# 小程序收款码打赏方案

## 一、可行性分析

### 可以放收款码吗？

**技术上可以，但有风险！**

微信小程序官方规定：
- 禁止在小程序内进行**虚拟支付**（绕过微信支付）
- 禁止引导用户到**外部支付**
- 收款码属于"诱导用户到外部支付"，可能被判定违规

### 风险等级

| 方式 | 风险 | 说明 |
|------|------|------|
| 直接放收款码 | ⚠️ 高风险 | 明显违规，可能被下架 |
| 放赞赏码 | ⚠️ 中等风险 | 灰色地带，看审核尺度 |
| 引导到公众号赞赏 | ✅ 较安全 | 通过合规渠道 |
| 完全不放 | ✅ 无风险 | 纯免费 |

## 二、各种方案详解

### 方案1：直接放微信收款码（不推荐）

**做法：**
```javascript
// pages/donate/donate.js
Page({
  previewImage() {
    wx.previewImage({
      urls: ['https://your-domain.com/payment-qr.jpg']
    });
  }

```

```xml

```

**风险：**
- 审核时可能被驳回
- 上线后被用户举报可能下架
- 属于"诱导用户到外部支付"

---

### 方案2：微信赞赏码（灰色地带）

**什么是赞赏码？**
- 微信官方提供的个人收款方式
- 路径：微信 → 我 → 服务 → 收付款 → 赞赏码

**做法：**
- 生成自己的赞赏码
- 截图上传到小程序
- 用户长按识别

**风险：**
- 比收款码稍好（因为是官方功能）
- 但仍可能被判定违规
- 审核尺度不统一

---

### 方案3：绑定公众号赞赏（推荐）

**这是最合规的方式！**

#### 操作步骤：

1. **注册订阅号**（个人即可）
   - 访问 mp.weixin.qq.com
   - 注册个人订阅号
   - 免费

2. **开通赞赏功能**
   - 需要发布3篇以上原创文章
   - 开通流量主
   - 申请赞赏账户

3. **小程序关联公众号**
   - 小程序后台 → 推广 → 关联公众号
   - 输入公众号AppID关联

4. **小程序内引导到公众号**

```javascript
// pages/donate/donate.js
Page({
  // 跳转到公众号文章（带赞赏）
  goToOfficialAccount() {
    wx.navigateToMiniProgram({
      appId: 'wx1234567890abcdef', // 公众号的AppID
      path: 'pages/index/index'
    });
  },

  // 或者复制公众号名称
  copyOfficialAccountName() {
    wx.setClipboardData({
      data: 'WordFlash官方',
      success: () => {
        wx.showModal({
          title: '感谢支持',
          content: '公众号名称已复制，请在微信搜索关注后赞赏',
          showCancel: false
        });
      }
    });
  }
});
```

```xml

  <view class="donate-card">
    <text class="title">☕ 请开发者喝杯咖啡</text>
```

**优点：**
- 完全合规
- 不会被下架
- 用户信任度高

**缺点：**
- 操作路径较长
- 转化率可能较低

### 方案4：流量主广告变现（最推荐）

**微信小程序官方广告**

#### 开通条件：
- 累计独立访客（UV）≥ 1000
- 无严重违规记录

#### 广告类型：

| 类型 | 位置 | 收益 |
|------|------|------|
| Banner广告 | 页面底部 | 较低 |
| 激励视频广告 | 用户主动观看 | 较高 |
| 插屏广告 | 页面切换时 | 中等 |
| 格子广告 | 页面内嵌 | 较低 |

#### 代码示例：

```javascript
// pages/index/index.js
Page({
  // 显示激励视频广告
  showRewardedAd() {
    const rewardedVideoAd = wx.createRewardedVideoAd({
      adUnitId: 'adunit-xxxxxxxxxxxxxxxx'
    });

    rewardedVideoAd.show().catch(() => {
      rewardedVideoAd.load().then(() => rewardedVideoAd.show());
    });

    rewardedVideoAd.onClose((res) => {
      if (res && res.isEnded) {
        // 用户完整观看了广告
        wx.showToast({ title: '感谢支持！', icon: 'success' });
        // 可以给用户一些奖励
      }
    });
  }
});
```

```xmln<!-- pages/index/index.wxml -->
<view class="container">
  <!-- Banner广告 -->
  <ad unit-id="adunit-xxxxxxxxxxxxxxxx" ad-type="banner"></ad>
  
  <!-- 内容区域 -->
  <view class="content">
    <!-- ... -->
  </view>
  
  <!-- 激励视频入口 -->
  <button class="btn-support" bindtap="showRewardedAd">
    🎬 观看广告支持开发者
  </button>
</view>
```

**优点：**
- 完全合规
- 无需企业资质
- 自动结算
- 用户体验较好（激励视频）

**缺点：**
- 需要1000用户才能开通
- 收益相对较低

## 四、WordFlash 建议方案

### 阶段1：初期（0-1000用户）

**策略：完全免费 + 引导关注公众号**


**策略：开通流量主 + 激励视频**

- 开通 Banner 广告（页面底部）

- 用户观看广告后获得额外生成次数

```javascript

```

## 五、注意事项

### 1. 审核避坑

**不要出现以下词汇：**
- "打赏"
- "捐赠"
- "付款"
- "购买"
- "充值"

**建议用词：**
- "支持开发者"
- "请杯咖啡"
- "关注公众号"
- "分享给朋友"

### 2. 页面设计

**避免：**
- 收款码占据页面主要位置
- 强制要求付费
- 功能与付费强绑定

**建议：**
- 放在设置页或不显眼位置
- 强调自愿原则
- 功能完全免费

### 3. 用户协议

在小程序中添加说明：
```
本小程序完全免费，所有功能无需付费即可使用。
如觉得好用，可以通过关注公众号等方式支持开发者。
```

## 六、总结

| 阶段 | 用户量 | 推荐方案 |
|------|--------|----------|
| 初期 | < 1000 | 完全免费 + 引导关注公众号 |
| 成长期 | 1000+ | 开通流量主广告 |
| 成熟期 | 10000+ | 注册企业 + 微信支付 |

**核心原则：**
1. 功能完全免费
2. 变现方式合规
3. 不强制用户付费
4. 优先通过广告变现
