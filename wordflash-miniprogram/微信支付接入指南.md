# 微信小程序支付接入指南

## 重要前提

**个人主体小程序无法接入微信支付！**

只有以下主体可以开通：
- 企业（有限公司、股份公司等）
- 个体工商户
- 政府/事业单位
- 其他组织

---

## 一、开通条件

### 1. 资质要求
| 主体类型 | 所需材料 |
|---------|---------|
| 企业 | 营业执照、对公账户、法人身份证 |
| 个体工商户 | 营业执照、法人银行卡、法人身份证 |
| 政府/事业单位 | 组织机构代码证、单位银行账户 |

### 2. 费用
- 小程序认证费：300元/年
- 微信支付费率：0.6%（每笔交易）
- 无开通费、无月租费

---

## 二、开通流程

### 步骤1：注册企业小程序
1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 注册小程序账号
3. 选择主体类型：企业
4. 上传营业执照等资料
5. 支付300元认证费
6. 等待审核（1-3个工作日）

### 步骤2：开通微信支付
1. 登录小程序后台
2. 点击"微信支付" → "开通"
3. 选择"新申请"（没有商户号）或"绑定一个已有的商户号"
4. 填写商户信息：
   - 商户名称
   - 经营类目（选择最匹配的）
   - 结算银行账户
5. 提交审核（1-5个工作日）

### 步骤3：签署协议
1. 审核通过后，会收到签约通知
2. 使用超级管理员微信扫码签约
3. 完成协议签署

### 步骤4：配置API密钥
1. 登录 [微信支付商户平台](https://pay.weixin.qq.com/)
2. 账户中心 → API安全
3. 设置APIv3密钥（32位随机字符串）
4. 下载API证书（.p12文件）

## 三、开发接入

### 1. 配置服务器域名
小程序后台 → 开发 → 开发管理 → 服务器域名

添加以下域名：
```
https://api.mch.weixin.qq.com
```

### 2. 后端服务搭建

微信支付必须在**后端服务器**完成签名，不能在前端直接调用！

#### 2.1 统一下单接口

```javascript
// 后端代码示例（Node.js）
const crypto = require('crypto');
const axios = require('axios');

// 商户配置
const config = {
  appId: 'wx1234567890abcdef',      // 小程序AppID
  mchId: '1234567890',               // 商户号
  apiKey: 'your_api_v3_key',         // APIv3密钥
  notifyUrl: 'https://your-domain.com/pay/notify'  // 支付结果通知地址
};

// 生成随机字符串
function generateNonceStr() {
  return Math.random().toString(36).substr(2, 15);
}

// 生成时间戳
function generateTimeStamp() {
  return Math.floor(Date.now() / 1000).toString();
}

// 统一下单
async function unifiedOrder(orderInfo) {
  const {
    body,           // 商品描述
    outTradeNo,     // 商户订单号
    totalFee,       // 总金额（分）
    openId          // 用户openid
  } = orderInfo;

  const params = {
    appid: config.appId,
    mch_id: config.mchId,
    nonce_str: generateNonceStr(),
    body: body,
    out_trade_no: outTradeNo,
    total_fee: totalFee,
    spbill_create_ip: '127.0.0.1',
    notify_url: config.notifyUrl,
    trade_type: 'JSAPI',
    openid: openId
  };

  // 生成签名
  const sign = generateSign(params, config.apiKey);
  params.sign = sign;

  // 发送请求
  const xml = buildXml(params);
  const response = await axios.post(
    'https://api.mch.weixin.qq.com/pay/unifiedorder',
    xml,
    { headers: { 'Content-Type': 'text/xml' } }
  );

  return parseXml(response.data);
}

// 生成签名（MD5）
function generateSign(params, key) {
  const sorted = Object.keys(params)
    .filter(k => params[k] !== '' && k !== 'sign')
    .sort()
    .map(k => `${k}=${params[k]}`)
    .join('&');
  
  const stringSignTemp = sorted + '&key=' + key;
  return crypto.createHash('md5')
    .update(stringSignTemp)
    .digest('hex')
    .toUpperCase();
}

// 构建XML
function buildXml(obj) {
  let xml = '<xml>';
  for (const key in obj) {
    xml += `<${key}><![CDATA[${obj[key]}]]></${key}>`;
  }
  xml += '</xml>';
  return xml;
}
```

#### 2.2 小程序支付参数生成

```javascript
// 后端：生成小程序调起支付所需的参数
function generatePayParams(prepayId) {
  const params = {
    appId: config.appId,
    timeStamp: generateTimeStamp(),
    nonceStr: generateNonceStr(),
    package: `prepay_id=${prepayId}`,
    signType: 'MD5'
  };

  // 生成支付签名
  params.paySign = generateSign(params, config.apiKey);
  
  return params;
}

// API接口：发起支付
app.post('/api/pay/create', async (req, res) => {
  try {
    const { body, totalFee, openId } = req.body;
    const outTradeNo = `ORDER${Date.now()}`;

    // 1. 统一下单
    const orderResult = await unifiedOrder({
      body,
      outTradeNo,
      totalFee,
      openId
    });

    if (orderResult.return_code !== 'SUCCESS') {
      throw new Error(orderResult.return_msg);
    }

    // 2. 生成支付参数
    const payParams = generatePayParams(orderResult.prepay_id);

    // 3. 保存订单到数据库（略）

    res.json({
      success: true,
      data: payParams
    });
  } catch (error) {
    res.json({
      success: false,
      message: error.message
    });
  }
});
```

#### 2.3 支付结果通知

```javascript
// 后端：处理微信支付回调
app.post('/pay/notify', async (req, res) => {
  const xmlData = req.body;
  const data = parseXml(xmlData);

  // 1. 验证签名
  const sign = generateSign(data, config.apiKey);
  if (sign !== data.sign) {
    return res.send(buildXml({
      return_code: 'FAIL',
      return_msg: '签名错误'
    }));
  }

  // 2. 处理业务逻辑
  if (data.return_code === 'SUCCESS' && data.result_code === 'SUCCESS') {
    const orderNo = data.out_trade_no;
    
    // 更新订单状态
    await updateOrderStatus(orderNo, 'paid');
    
    // 给用户添加权益（如开通会员）
    await grantUserBenefits(data.openid, orderNo);
  }

  // 3. 返回成功响应
  res.send(buildXml({
    return_code: 'SUCCESS',
    return_msg: 'OK'
  }));
});
```

### 3. 小程序前端代码

```javascript
// pages/pay/pay.js
Page({
  data: {
    product: {
      name: 'WordFlash 高级会员',
      price: 19.9
    }
  },

  // 发起支付
  async initiatePayment() {
    try {
      // 1. 获取用户openid（需要先登录）
      const openId = await this.getOpenId();

      // 2. 调用后端接口创建订单
      const res = await wx.request({
        url: 'https://your-domain.com/api/pay/create',
        method: 'POST',
        data: {
          body: this.data.product.name,
          totalFee: Math.round(this.data.product.price * 100), // 转换为分
          openId: openId
        }
      });

      if (!res.data.success) {
        throw new Error(res.data.message);
      }

      const payParams = res.data.data;

      // 3. 调起微信支付
      const payRes = await wx.requestPayment({
        timeStamp: payParams.timeStamp,
        nonceStr: payParams.nonceStr,
        package: payParams.package,
        signType: payParams.signType,
        paySign: payParams.paySign
      });

      // 4. 支付成功
      wx.showToast({
        title: '支付成功',
        icon: 'success'
      });

      // 5. 跳转到成功页面或刷新用户权益
      this.refreshUserStatus();

    } catch (error) {
      console.error('支付失败:', error);
      wx.showToast({
        title: error.message || '支付失败',
        icon: 'none'
      });
    }
  },

  // 获取用户openid
  async getOpenId() {
    // 方式1：通过登录获取（推荐）
    const loginRes = await wx.login();
    const code = loginRes.code;

    const res = await wx.request({
      url: 'https://your-domain.com/api/auth/code2session',
      method: 'POST',
      data: { code }
    });
    
    return res.data.openid;
  },

  // 刷新用户状态
  refreshUserStatus() {

  }
});
```

## 五、常见问题

### Q: 个人开发者怎么办？
A: 个人无法开通微信支付，解决方案：
1. 注册个体工商户（成本低，手续简单）
2. 使用第三方收款（如赞赏码，但不正规）
3. 先做免费版，积累用户后再注册企业

### Q: 可以用别人的商户号吗？
A: 技术上可以，但不建议：
- 资金进入他人账户
- 税务风险
- 无法保证资金安全

### Q: 支付费率可以降低吗？
A: 标准费率0.6%，部分行业可申请优惠：
- 公立医院：0%
- 非盈利学校：0%
- 部分民生行业：0.2%

### Q: 用户付款后钱到哪里？
A: 直接结算到商户号绑定的对公账户或法人银行卡
- T+1 自动结算（次日到账）
- 可在商户平台查看流水

### Q: 需要服务器吗？
A: **必须需要**！原因：
- 支付签名必须在服务端完成
- 需要接收支付结果通知
- 需要处理订单状态

## 六、替代方案（个人开发者）

如果你是个人开发者，暂时无法开通微信支付，可以考虑：

### 方案1：完全免费
- 所有功能免费
- 通过广告变现（流量主）
- 积累用户后再考虑商业化

### 方案2：引导外部付费
- 小程序内展示二维码
- 引导用户到网页/H5支付
- 支付后手动开通权益（不推荐，体验差）

### 方案3：注册个体工商户
- 成本：营业执照代办约500-1000元
- 时间：3-7个工作日
- 后续：每年记账报税约2000元/年
