# WordFlash 项目常见问题与解决方案

> 本文档记录了项目开发、发布、运营过程中遇到的所有非技术 Bug 类问题，供后续参考。

## 一、微信账号类型选择

### Q：服务号、公众号、小程序有什么区别？

| 类型 | 定位 | 消息位置 | 发送频次 | 谁能注册 |
|------|------|---------|---------|---------|
| 订阅号 | 内容传播 | 折叠在文件夹 | 每天1次 | 个人/企业 |
| 服务号 | 服务交互 | 聊天列表 | 每月4次 | 仅企业 |
| 小程序 | 应用工具 | 不主动发消息 | 不限制 | 个人/企业 |

**WordFlash 选择小程序的原因：**
1. 需要本地存储用户数据
2. 需要复杂交互（闪卡翻转、AI 生成）
3. 个人开发者可以注册
4. 不需要每天推送消息

## 二、微信支付接入

### Q：个人开发者能接入微信支付吗？

**不能。** 只有企业或个体工商户才能开通微信支付。

### Q：小程序里能放收款码/赞赏码吗？

**不能。** 微信禁止在小程序内：
- 放置个人收款码
- 放置赞赏码
- 引导用户到外部支付

这些都属于"诱导外部支付"，会被下架。

### Q：个人开发者怎么变现？

| 方案 | 合规性 | 条件 |
|------|--------|------|
| 流量主广告 | ✅ 完全合规 | 累计 1000 UV |
| 完全免费 | ✅ 完全合规 | 无 |
| 引导到公众号赞赏 | ⚠️ 灰色 | 需注册订阅号 |
| 注册企业开通支付 | ✅ 完全合规 | 需企业/个体户资质 |

### Q：流量主的 1000 UV 是什么意思？

UV = 独立访客数。1000 个不同的人打开过你的小程序即可，同一个人多次打开只算 1 个。查看路径：微信公众平台 → 统计 → 访问分析。

## 三、AI 服务配置

### Q：原始项目用的什么 AI？

原始项目代码默认值是 DeepSeek，但实际运行时被加密配置覆盖，**实际使用的是阿里云通义千问**。

| 配置项 | 值 |
|--------|-----|
| API 地址 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 模型 | `qwen-turbo` |
| API Key | 加密存储在 `data/.secrets.enc` 中 |

### Q：如何解密原始项目的 API Key？

加密密码存储在 `.env` 文件的 `SECRET_PASSWORD` 字段中。使用 `crypto-utils.ts` 中的 AES-256-GCM 解密方法，配合 `.salt` 文件和密码即可解密。

### Q：阿里云通义千问的免费额度？

| 模型 | 免费额度 |
|------|---------|
| qwen-turbo | 每月 100 万 Token 永久免费 |
| qwen-plus | 新用户送 100 万 Token |
| qwen-max | 新用户送 100 万 Token |

100 万 Token 约可生成 1000 次词库，完全够个人使用。

### Q：DeepSeek 和阿里云通义千问怎么选？

| 特性 | DeepSeek | 通义千问 |
|------|----------|---------|
| 价格 | ¥1/百万token | qwen-turbo 永久免费 |
| 中文能力 | 优秀 | 优秀 |
| 国内访问 | 直连 | 直连 |
| API 兼容 | OpenAI 格式 | OpenAI 兼容格式 |

**建议：** 个人开发者优先用通义千问（免费），超出额度后切换 DeepSeek（便宜）。

## 四、小程序发布流程

### Q：发布需要哪些步骤？

1. 注册小程序账号（个人即可）
2. 获取 AppID
3. 下载微信开发者工具，导入项目
4. 开发调试，修复 Bug
5. 上传代码
6. 提交审核（1-3 个工作日）
7. 审核通过后发布

### Q：需要配置服务器域名吗？

**开发阶段：** 不需要，勾选"不校验合法域名"即可。

**上线阶段：** 必须配置。需要在微信公众平台添加：
- `https://dashscope.aliyuncs.com`（AI 服务）
- `https://dict.youdao.com`（有道词典发音和释义）

### Q：个人开发者能发布什么类目？

WordFlash 属于"工具-效率"或"教育-在线教育"类目，个人开发者可以正常发布。

## 六、数据存储设计

### Q：为什么选择纯本地存储？

| 方案 | 优点 | 缺点 |
|------|------|------|
| 纯本地存储 | 无需服务器、无需账号、隐私安全 | 换手机需手动迁移 |
| 云开发 | 数据同步、不丢数据 | 有成本、需账号体系 |
| 自建服务器 | 完全可控 | 开发成本高 |

**WordFlash 选择纯本地存储的原因：**
1. 不需要为每个用户建立账户
2. 不需要集中式数据库服务器
3. 用户的词库和学习进度只在个人手机上
4. 隐私安全，数据不上传

### Q：本地存储的限制？

- 微信小程序本地存储上限 **10MB**
- 卸载小程序会丢失数据
- 建议提供数据导出/导入功能

## 七、图标和素材

### Q：小程序头像需要什么尺寸？

| 用途 | 尺寸 |
|------|------|
| 小程序头像 | 512×512 |
| tabBar 图标 | 81×81 |
| 启动页图标 | 108×108 |

### Q：tabBar 图标有什么要求？

- 必须是**本地 PNG 文件**
- 不能是网络图片
- 未选中和选中状态需要两个不同的文件
- 建议大小 81×81 像素

## 八、审核注意事项

### Q：审核容易被驳回的原因？

1. 功能不完整（有按钮但点击无响应）
2. 内容违规（敏感词汇）
3. 类目选择不当
4. 隐私政策不完善
5. 有诱导外部支付的嫌疑

### Q：审核时应该注意什么？

- 确保所有按钮和功能都能正常使用
- 不要出现"打赏"、"捐赠"、"付款"等词汇
- AI 功能需要用户自行配置 API Key，不内置
- 添加隐私政策说明数据存储方式

## 九、项目架构决策记录

### 决策 1：纯本地存储 vs 云端存储

**选择：** 纯本地存储

**原因：**
- 不需要用户注册登录
- 不需要服务器成本
- 隐私安全
- 符合"即用即走"的小程序理念

### 决策 2：原生小程序 vs uni-app/Taro

**选择：** 原生小程序

**原因：**
- 项目相对简单，不需要跨平台
- 原生性能最好
- 不引入额外框架依赖
- 调试方便

### 决策 3：AI 服务选择

**选择：** 阿里云通义千问（qwen-turbo）

**原因：**
- 每月 100 万 Token 永久免费
- 中文能力强
- 国内直连，速度快
- OpenAI 兼容接口，切换成本低
