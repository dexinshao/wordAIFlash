## 问题 1：词库显示有词但点击进去没有单词

### 问题描述
用微信开发者工具打开后，每个词库上显示有 xxx 词，但点击"学习"或"列表"进去没有单词。

### 原因分析
- `db.ts` 使用 `Taro.getStorageSync` 本地存储数据
- 内置词库数据（`src/data/lib-*.json`）没有被自动导入到数据库
- 用户首次使用时，本地存储为空，导致词库列表显示有词（从 meta.json 读取），但实际单词数据未加载

### 解决方案
创建 `src/services/init-data.ts` 文件，在首次使用时从数据文件导入词库数据到本地存储。

## 问题 3：微信小程序中无法正确加载本地数据文件

### 尝试方案 1：使用 Taro.request 加载
**结果**：失败
**原因**：微信小程序中 `Taro.request` 只能发网络请求，不能读取本地文件。

### 尝试方案 2：使用 FileSystemManager.readFileSync
**结果**：失败，报 `readFileSync:fail permission denied`
**原因**：微信小程序 `FileSystemManager` 只能访问用户目录（如 wxfile://），不能访问项目目录文件。

### 尝试方案 3：使用 require() 动态路径
**结果**：失败，报 `Cannot find module '../../data/meta.js'`
**原因**：
- 动态路径 `require(filePath)` 在编译时无法被 webpack 正确处理
- 微信小程序中 `require()` 只能加载编译时已知的静态模块

### 尝试方案 4：使用静态 require() 路径
**结果**：成功 ✅
**实现**：在 `init-data.ts` 中为 each 数据文件写死静态 `require()` 路径：

```typescript
function loadJSON(filePath: string): any {
  try {
    let module;
    if (filePath.includes('meta.json')) {
      module = require('../data/meta.js');
    } else if (filePath.includes('lib-1')) {
      module = require('../data/lib-1.js');
    } else if (filePath.includes('lib-2')) {
      module = require('../data/lib-2.js');
    }
    // ... 其他词库
    return module && (module.default || module);
  } catch (err) {
    console.warn(`无法加载文件: ${filePath}`, err);
    throw err;
  }
}
```

### 配套修改：JSON 转 JS 模块
由于 `require()` 需要加载 JS 模块，需要将 JSON 数据文件转换为 JS 格式：

```bash
cd src/data
for f in *.json; do echo "module.exports = $(cat $f);" > "${f%.json}.js"; done
```

### Taro 配置修改
在 `config/index.ts` 中配置 copy 模式，确保数据文件被复制到输出目录：

```typescript
copy: {
  patterns: [
    { from: 'src/data', to: '../weapp/data' },
    { from: 'src/data/*.js', to: '../weapp/data' }
  ],
  options: {}
}
```

## 问题 4：单词列表页面打开太慢

### 问题描述
打开单词列表时性能问题严重：
```
数据传输长度过长 setData 数据传输长度为 1154 KB，存在有性能问题！
```

### 原因分析
- 一次性通过 `setData` 传输所有单词数据到视图层
- 某些词库单词数量多，数据量大（如 lib-8.js 达 1.22 MiB）

### 解决方案：分页加载
重写 `src/pages/wordlist/index.tsx`，实现分页加载：

1. **添加分页相关状态**
   ```typescript
   const PAGE_SIZE = 50;
   this.state = {
     words: [],        // 所有单词（数据层）
     displayWords: [], // 当前显示的单词（视图层）
     currentPage: 1,
     hasMore: true
   };
   ```

2. **修改 loadWords 支持分页**
   ```typescript
   loadWords = (reset: boolean = true) => {
     if (reset) {
       const allWords = db.getWords(...);
       const displayWords = allWords.slice(0, PAGE_SIZE);
       this.setState({
         words: allWords,
         displayWords,
         currentPage: 1,
         hasMore: allWords.length > PAGE_SIZE
       });
     }
   }
   ```

3. **添加 loadMore 方法**
   ```typescript
   loadMore = () => {
     const { words, currentPage } = this.state;
     const nextPage = currentPage + 1;
     const start = (nextPage - 1) * PAGE_SIZE;
     const end = start + PAGE_SIZE;
     const newWords = words.slice(0, end);
     this.setState({
       displayWords: newWords,
       currentPage: nextPage,
       hasMore: end < words.length
     });
   }
   ```

4. **使用 ScrollView + onScrollToLower**
   ```tsx
   <ScrollView scrollY onScrollToLower={this.loadMore}>
     {/* 单词列表 */}
     {this.state.hasMore && <Button onClick={this.loadMore}>加载更多...</Button>}
   </ScrollView>
   ```
